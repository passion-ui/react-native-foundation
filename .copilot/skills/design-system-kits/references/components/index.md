# Components Reference

Individual reference files for all UI components exported by `@passionui/react-native-foundation`.

## Form Components
- [Button](./button.md) — Pressable button with 6 types and 3 sizes
- [IconButton](./icon-button.md) — Circular/rounded icon-only button
- [Input](./input.md) — Text input with floating label, error, leading/trailing icons
- [InputOTP](./input-otp.md) — One-time password input
- [InputMoney](./input-money.md) — Currency-formatted input
- [InputSearch](./input-search.md) — Search input with icon
- [InputTextArea](./input-text-area.md) — Multi-line text area
- [InputDropDown](./input-drop-down.md) — Dropdown trigger input
- [CheckBox](./checkbox.md) — Toggle with checked/unchecked/indeterminate
- [Radio](./radio.md) — Single selection within a group
- [Switch](./switch.md) — Toggle switch
- [Stepper](./stepper.md) — Increment/decrement control

## Display Components
- [Text](./text.md) — Typography with 11 presets and multi-font support
- [Icon](./icon.md) — Vector icon with adapter support
- [Image](./image.md) — Image with loading skeleton and error fallback
- [Badge](./badge.md) — Small status indicator (dot or label)
- [Tag](./tag.md) — Colored label chip with optional icon
- [Divider](./divider.md) — Line separator (solid or dashed)
- [SizedBox](./sized-box.md) — Simple spacer
- [Skeleton](./skeleton.md) — Shimmer loading placeholder
- [LoopText](./loop-text.md) — Animated cycling text

## Feedback Components
- [ProgressBar](./progress-bar.md) — Animated progress indicator
- [Toast](./toast.md) — Notification banner
- [Popup](./popup.md) — Modal dialog with actions
- [SheetPicker](./sheet-picker.md) — Searchable selection list

## Advanced Components
- [TabView](./tab-view.md) — Tabbed content with PagerView
- [Pagination](./pagination.md) — Page indicator (dot/number)
- [Steps](./steps.md) — Step progress indicator
