# Color Palette

```typescript
import { Colors } from '@passionui/react-native-foundation';
```

12+ color families, each with 11 shades (01 = darkest, 11 = lightest):

| Family | Shades |
|--------|--------|
| `black` | `Colors.black`, `Colors.black_03` ... `Colors.black_18` |
| `pink` | `Colors.pink_01` ... `Colors.pink_11` |
| `violet` | `Colors.violet_01` ... `Colors.violet_11` |
| `indigo` | `Colors.indigo_01` ... `Colors.indigo_11` |
| `blue` | `Colors.blue_01` ... `Colors.blue_11` |
| `mint` | `Colors.mint_01` ... `Colors.mint_11` |
| `green` | `Colors.green_01` ... `Colors.green_11` |
| `lime` | `Colors.lime_01` ... `Colors.lime_11` |
| `yellow` | `Colors.yellow_01` ... `Colors.yellow_11` |
| `gold` | `Colors.gold_01` ... `Colors.gold_11` |
| `orange` | `Colors.orange_01` ... `Colors.orange_11` |
| `red` | `Colors.red_01` ... `Colors.red_11` |

Also: `Colors.white`, `Colors.black`

**Convention:** `_03` for default, `_07` for light, `_08`-`_09` for container.
